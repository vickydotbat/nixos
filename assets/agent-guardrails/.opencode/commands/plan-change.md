---
description: Build a minimal implementation plan after reading repository context
---

Load `context-discovery` first.
Choose the smallest relevant set of skills:

- `architecture-responsibility`
- `workflow-preservation`
- `concurrency-async-safety`
- `testing-discipline`
- `code-hygiene`
- `dependency-discipline`
- `managed-environment`
- `git-safety`

Do not edit files.

Produce a plan that includes:

1. Compact awareness packet.
2. Minimal files likely to change.
3. Proposed steps.
4. Tests/checks to run.
5. Risks and questions.

Stop after the plan.
